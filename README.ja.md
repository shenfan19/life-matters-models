# Life Matters（大德曰生）

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md)

Life Matters は、健康や行動について公表された研究成果を、実行・組み合わせが可能な動的モデルにまとめるオープンな[研究プロジェクト](https://lifematters.dev/)です。モデルライブラリは [LM YAML 形式の仕様](docs/LM_format_1.0.md)とモデル例を公開し、[リファレンスエンジン](https://github.com/shenfan19/life-matters-reference-engine)はモデルを実行して、複数の目標の間にあるトレードオフを比較します。

## 結果の読み方

モデルの結果は研究・教育用です。個々のモデルの出典、前提、検証状況を確認してから解釈してください。
