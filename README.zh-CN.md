# Life Matters（大德曰生）

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md)

Life Matters 是一个开放研究项目，将已发表的健康与行为研究整理成可运行、可组合的动力学模型。模型库提供 LM YAML 格式规范和示例模型，参考引擎负责运行模型，帮助读者比较不同目标之间的取舍。

## 浏览项目

[主页](https://shenfan19.github.io/life-matters/) · [Life Matters 项目站](https://lifematters.dev/) · [在线演示](https://ref-engine.lifematters.dev) · [模型格式](docs/LM_format_1.0.md) · [参考引擎](https://github.com/shenfan19/life-matters-reference-engine)

## 如何解读结果

模型结果用于研究和教育。解读具体模型前，请查阅其来源、假设和验证状态。
