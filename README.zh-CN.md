# Life Matters（大德曰生）

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md)

Life Matters 是一个[开放研究项目](https://lifematters.dev/)，将已发表的健康与行为研究整理成可运行、可组合的动力学模型。模型库提供 [LM YAML 格式规范](docs/LM_format_1.0.md)和示例模型，[参考引擎](https://github.com/shenfan19/life-matters-reference-engine)负责运行模型，帮助读者比较不同目标之间的取舍。

## 如何解读结果

模型结果用于研究和教育。解读具体模型前，请查阅其来源、假设和验证状态。
