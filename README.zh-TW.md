# Life Matters（大德曰生）

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md)

Life Matters 是一個開放研究計畫，將已發表的健康與行為研究整理成可執行、可組合的動力學模型。模型庫提供 LM YAML 格式規格和範例模型，參考引擎負責執行模型，協助讀者比較不同目標之間的取捨。

## 瀏覽計畫

[主頁](https://shenfan19.github.io/life-matters/) · [Life Matters 計畫網站](https://lifematters.dev/) · [線上演示](https://ref-engine.lifematters.dev) · [模型格式](docs/LM_format_1.0.md) · [參考引擎](https://github.com/shenfan19/life-matters-reference-engine)

## 如何解讀結果

模型結果用於研究和教育。解讀特定模型前，請查閱其來源、假設和驗證狀態。
