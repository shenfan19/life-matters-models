# Design Decision Records

Each file records one design decision, in a format inspired by [ADR](https://adr.github.io/).

> **Numbering rule (as of 2026-07-15)**: this repository and the `life-matters-reference-engine` repository (`docs/reference_engine/decisions/`)
> share a single global numbering sequence and no longer count independently; before creating a new ADR, check
> the latest number in both repositories and take the larger one plus 1. Before 2026-07-15 the two counted
> independently, which once produced a legacy collision where 0128/0129/0130 were reused for different content
> in each repository (this repository's original 0128/0129 have been renumbered to 0131/0132; `life-matters-reference-engine`'s
> 0128/0129/0130 were left unchanged, with no retroactive renumbering).
